# Automatique_Avanc-e
Ce dépôt regroupe des stratégies de commande dans le cadre du  connaissance d’Automatique Avancée, notamment la commande linéaire, la linéarisation entrée-sortie et la commande par platitude différentielle. Il présente les principes théoriques, les méthodes de conception et leur mise en œuvre pour l’analyse et le contrôle de systèmes dynamiques.
